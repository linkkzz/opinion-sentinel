# 舆情智析平台导入测试包

每次导入时，在管理员端同时选择一份 Excel 和与它对应的媒体 ZIP。Excel 中已经填写好图片、视频文件名，系统会自动关联。

## 文件对应关系

| Excel | 媒体ZIP | 用途 |
|---|---|---|
| `01_校园食品安全_第一批20条.xlsx` | `food-a_媒体.zip` | 首次创建任务并导入 |
| `02_校园食品安全_第二批增量8条.xlsx` | `food-b_媒体.zip` | 同一任务后续增量导入 |
| `03_新能源汽车质量争议25条.xlsx` | `auto_媒体.zip` | 独立任务测试 |
| `04_城市音乐节服务舆情24条.xlsx` | `festival_媒体.zip` | 独立任务测试 |
| `05_国产游戏上线口碑30条.xlsx` | `game_媒体.zip` | 独立任务测试 |

## 推荐完整流程

1. 创建“校园食品安全舆情监测”任务，配置关键词：`食堂卫生、食品留样、学生反馈、校方回应、整改进度`。
2. 在管理员端进入任务，上传第一批20条 Excel 和 `food-a_媒体.zip`。
3. 启动AI分析；分析几条后暂停，生成首份应对策略。
4. 继续分析，完结任务并生成报告 V1。
5. 重新开启任务，导入第二批增量8条 Excel 和 `food-b_媒体.zip`。
6. 再次启动AI分析。新数据完成研判后，应当可以更新应对策略。
7. 再次完结任务并生成报告 V2。管理员端应看到 V1、V2，用户端默认查看 V2。

## 媒体说明

- 每个ZIP包含2张JPG图片和1段MP4短视频。
- `媒体原文件` 文件夹保留了解压后的原始素材，便于人工查看。
- 所有内容均为虚构测试数据，源链接使用 `example.com`，不对应真实社交平台内容。
- 重复导入同一Excel时，系统会根据原始数据ID跳过重复数据。
- 每条数据已经分别填写点赞量、评论量、转发量和阅读/播放量；系统会自动计算互动总量。
